# 한국수어 30클래스 GRU · robust v2

이 폴더의 가중치는 웹캠 기본 실행에 사용합니다. 데이터 ZIP 없이 clone 후 설치해서 사용할 수 있습니다.

- model.pt: CPU에서 불러오는 PyTorch 가중치, 정규화 통계와 클래스 순서
- classes.json: 단어 23개·문장 7개와 출력/게임 메타데이터
- metrics.json: 합성 변형 자료 비교 결과
- SHA256(model.pt): `a947122ead740ada68f68c5e0bca881028cd071f1d1cc99afe53aad16decf8b9`

원본은 촬영자 REAL01의 정면 동작 30개(클래스당 1개)입니다. 속도·경계·좌표·짧은 손 누락 증강으로 750개 입력을 만들어 180 epoch 학습했습니다.
합성 자료 성능은 새 사용자나 실제 웹캠 검증 정확도가 아닙니다. 원본 키포인트·morpheme·영상·개별 촬영 경로 기록은 포함하지 않습니다.

설치·실행은 [팀원용 안내](../../docs/ksl_team_guide.md)를 참고하세요. MediaPipe 공식 손/몸 추적 모델은 설치 단계에서 별도로 다운로드합니다.
