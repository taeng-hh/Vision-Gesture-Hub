# 8단어 웹캠 수어 인식

저장소 루트의 CMD에서 실행합니다. 기존 PC/발표 제어 앱과 별도 수어 전용 진입점입니다.

```cmd
.venv\Scripts\python.exe scripts\download_pose_model.py
.venv\Scripts\python.exe live_ksl.py
```

카메라가 안 열리면 `live_ksl.py --camera 1`을 사용하세요.
이미 설치한 MediaPipe, OpenCV, NumPy, Pillow를 사용합니다. 손 모델과 별도로
공식 Pose Landmarker Lite 모델 하나가 추가로 필요합니다.

1. 상반신/양 어깨/손이 보이도록 정면에 앉습니다. 조명과 배경을 단순하게 유지합니다.
2. Space로 단어 녹화를 시작하고 한 단어를 수행합니다.
3. Space로 완료하거나, 양손을 화면 밖으로 0.35초 이상 뺍니다.
4. 인식 성공 시 단어가 누적되고 지원하는 조합이면 문장이 자동 표시됩니다.
5. 다음 단어는 다시 Space로 녹화합니다. Enter는 문장 확정, Backspace는 마지막 단어 삭제,
   C는 초기화, Q/Esc/창 닫기는 종료입니다.

현재 단어: 나, 머리, 아프다, 병원, 가다, 밥, 부탁, 돕다.
의미 조합 예시: 나+머리+아프다 -> 저는 머리가 아파요 / 병원+가다 -> 병원에 가요 /
밥+부탁 -> 밥을 주세요 / 돕다+부탁 -> 도와주세요.
실제 수어 표현은 사전/수어 사용자에게 확인하세요. 이 규칙은 수어 문법을 검증한 번역기가 아닙니다.

## 연결 방식과 한계

- 기존 8단어 AI Hub 모델을 그대로 사용합니다. 추가 재학습/임계값 완화는 하지 않았습니다.
- 카메라의 원본(비반전) 영상에서 손·몸 자세를 추출하고 화면만 거울 반전합니다.
- MediaPipe의 왼/오른 어깨를 BODY_25 5/2번으로 매핑합니다.
- 손은 pose의 왼/오른 손목과 거리로 연결합니다. 연결이 모호하면 인식을 취소합니다.
- X/Y를 영상 픽셀 단위로 변환하고 신뢰도와 조합합니다. Z를 신뢰도로 사용하지 않습니다.
- 추적 실패/긴 입력 끊김/6초 초과 구간은 취소합니다. 손만 들어올린 대기 자세를
  무조건 단어로 인식하지 않도록 Space로 단어 구간을 명시합니다.
- AI Hub 키포인트와 MediaPipe는 추출기가 다릅니다. 좌표 형식을 맞추는 것만으로
  새 사람의 인식 정확도가 보장되지 않습니다. 오인식/거절이 잦으면 웹캠 데이터를 추가해
  재학습하는 것이 다음 단계입니다. 실제 사용자의 정확도는 별도 측정해야 합니다.
- 거리/차이는 분류 점수이고 확률이나 정확도가 아닙니다.
- 웹캠 영상/관절은 저장하거나 외부로 전송하지 않습니다.
