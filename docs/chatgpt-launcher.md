# PC 모드에서 ChatGPT 열기

1. 프로그램을 실행하고 `2`로 PC 제어 모드를 선택합니다.
2. `E` 또는 ENABLE 버튼으로 OS 제어를 켭니다.
3. 화면 상단 메뉴 영역을 피해 카메라에 브이(검지와 중지를 편 자세)를 약 1초 유지합니다.
4. 기본 브라우저에 `https://chatgpt.com/`이 열립니다. 로그인은 브라우저에서 직접 합니다.

브이 인식 신뢰도가 80% 이상일 때만 시간을 계산합니다. 브이를 유지하는 동안
커서 이동과 클릭은 멈춥니다. 다시 열려면 손을 치우거나 다른 모양을 0.3초 이상
유지해야 하며, 실행 사이에는 최소 5초 간격이 있습니다.

ChatGPT 데스크톱 앱 설치 여부와 관계없이 웹사이트를 여는 기능입니다.
기본 브라우저가 등록되어 있어야 합니다.

## 그림판 실행

PC 제어를 켠 상태에서 엄지·검지·새끼손가락을 펴고 중지·약지를 접은
`ILoveYou` 손모양을 1초 유지하면 Windows 그림판(`mspaint.exe`)을 엽니다.
ChatGPT와 같은 신뢰도, 재실행 간격과 손모양 해제 조건이 적용됩니다.
열린 그림판에서는 기존 검지 커서 이동과 엄지·중지 핀치 클릭으로 도구를
선택하거나 캔버스에 점을 찍을 수 있습니다. 현재 클릭은 드래그가 아니므로
손을 움직이며 연속선을 그리는 기능은 포함되지 않습니다.
