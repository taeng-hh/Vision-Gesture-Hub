# 30클래스 웹캠 인식

프로젝트 폴더에서 실행:

```cmd
.venv\Scripts\python.exe main.py --live-ksl
```

수어인식실행.cmd를 더블클릭해도 됩니다. 기본 모델은 models/ksl30_robust_v2입니다. 기존 모델은 models/ksl30_complete_v1에 보존되어 있습니다.
Space로 시작하고 단어 또는 문장 하나를 수행한 다음 Space로 완료합니다.
단어는 누적하고 문장은 누적 단어를 비운 뒤 해당 문장을 출력합니다.
Enter는 누적 단어를 조합하고 Backspace는 삭제, C는 초기화, Q/Esc는 종료합니다.
단어 조합은 커피+부탁, 밥+부탁, 나+배고프다/행복/슬프다, 수어+좋다에 규칙을 적용하며 나머지는 인식 단어를 이어 표시합니다.
최대 12초이며 Space로 완료합니다. 손이 잠깐 가려져도 자동 완료하지 않습니다.
상반신과 양쪽 어깨를 화면에 보여야 합니다. 0.6초 미만의 추적 실패는 복구를 기다리고, 긴 실패는 취소합니다. 실제 프레임 시간 간격을 보정합니다.

현재 단일 촬영자 30개 정면 클립으로 학습한 실험용 모델입니다.
학습 자료 재인식 30/30은 웹캠 정확도가 아닙니다. AIHub와 MediaPipe 추출기 차이도 있습니다.
낮은 점수/작은 점수 차이는 거절하며 임계값은 아직 보정하지 않았습니다.
모드 선택 없이 모델의 word/sentence 클래스 유형으로 출력합니다. 자유로운 수어 문장 번역이 아닙니다.
영상은 저장하거나 전송하지 않으며 game_action을 운영체제/게임 명령으로 실행하지 않습니다.
이전 모델 실행: .venv\Scripts\python.exe live_ksl.py --model models/ksl_aihub_first.npz

## 인식이 보류되는 경우

보류 결과에 후보 이름, 점수와 1·2위 차이를 표시합니다. 확정 자막에는 추가하지 않습니다.
동작 시작 자세를 잡은 뒤 Space를 누르고, 동작을 끝낸 직후 Space로 완료하세요.
시작/끝에 긴 준비 동작이 들어가면 학습 동작과 달라질 수 있습니다.
임계값은 그대로 유지합니다. 표시 점수는 실제 정답 확률로 보정한 값이 아닙니다.
새 증강 모델은 동작 속도, 입력 경계, 작은 좌표 오차, 짧은 손 누락을 합성해 학습합니다.
합성 자료 성능은 다른 사람이나 실제 웹캠에서의 검증 정확도가 아닙니다.
AIHub 추출기와 MediaPipe의 차이 및 촬영자 1명이라는 한계는 남아 있습니다.
