# 게임 인식 범위 조정

최근 최대 2.4초 입력을 여러 길이로 비교하며 0.5초부터 0.2초마다 분류합니다. 연속 확인과 0.8초 쿨다운을 적용합니다.
Space 입력이나 자동 시작/끝 감지는 추가하지 않았습니다.
게임에서는 game_action이 있는 7개 클래스 안의 비교 점수를 사용합니다. 일반 수어 인식은 30개 전체 그대로입니다.
게임 비교 점수 .75, 1·2위 차이 .15 외에도 원래 전체 클래스 점수 .35 및 게임 클래스 점수 합 .40 이상을 요구합니다.
비게임 클래스의 전체 점수가 .65 이상이면 조작을 보류합니다. 친구나 안녕하세요를 방향으로 강제로 매핑하지 않습니다.
보류 화면의 ‘비교’는 게임 후보 사이 상대 점수, ‘전체’는 전체 30개 기준 해당 후보 점수입니다. 정답 확률로 해석하지 마세요.
이 기준은 새 사용자에게 보정된 임계값이 아닙니다. 이전보다 오조작이 늘어날 가능성도 있어 실제 사용 확인이 필요합니다.
모델 가중치는 변경하지 않았습니다. 손동작·추적기 차이에 의한 지속적인 오인식까지 해결됐다고 볼 수 없습니다.
CNN 보조만 끄려면 게임 중 B를 누릅니다. 이때도 게임용 키포인트 판정과 여러 길이 비교는 유지됩니다.


## 동일 구간 비교 및 여러 길이 입력

0.2초마다 최근 최대 2.4초를 유지하고, 0.8/1.2/1.6/2.4초의 사용 가능한 구간을 함께 평가합니다.
양 방식은 같은 32시점 좌표와 같은 모델 출력 점수를 공유합니다. 일반은 30클래스, 게임은 게임용 클래스 비교와 전체 점수 거절 조건을 적용합니다.
조건을 통과한 구간 중 해당 후보의 전체 점수가 가장 높은 구간을 선택합니다. 단순히 게임용 비교 점수가 높은 구간을 고르지 않습니다.
두 번 연속 같은 조작을 확인한 뒤 실행하며 기존 0.8초 쿨다운을 유지합니다. Space나 동작 끝 감지는 사용하지 않습니다.
화면의 ‘일반’과 ‘게임 전체’는 30개 기준 점수이고 ‘비교’는 게임 클래스 내부의 상대 점수입니다.
‘확인 1/2’는 점수를 통과했지만 다음 예측의 일치를 기다리는 상태입니다.
원래 1.6초 고정 구간보다 잘리는 동작을 줄일 수 있지만 여러 구간을 평가하면 오조작 기회도 늘 수 있어 실제 사용자 검증이 필요합니다.


비슷한 점수(최고 전체 점수에서 .05 이내)를 가진 후보 구간은 더 긴 구간을 우선합니다.
일반·게임 후보가 일치하고 전체 점수 .99 및 일반 점수 차이 .9 이상이면 추가 반복 확인 없이 실행합니다.
그 밖의 결과는 최소 1.25초 문맥과 같은 조작 연속 확인을 요구합니다. 임계값은 실사용 검증이 필요합니다.
예측은 이전 실행 시점이 아니라 고정 간격 일정으로 예약해 프레임 반올림 지연이 계속 누적되지 않도록 합니다.
이 페이지의 앞선 1.6초 고정/항상 두 번 확인 설명은 과거 방식이며 위 개선 규칙을 우선합니다.
