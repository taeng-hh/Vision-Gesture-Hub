# 게임 CNN 보조와 기존 모델 전환

기존 게임의 Space 없는 슬라이딩 자동 인식 방식을 유지합니다. 별도 시작/끝 감지는 사용하지 않습니다.

- 기존 실행: `게임실행.cmd` (기존 가상환경, 키포인트 단독으로 시작)
- CNN 실행: `게임실행_CNN보조.cmd` (CNN 보조로 시작)
- 게임 중 B: 기존 키포인트 단독 / C: CNN 보조. 전환 시 이전 입력과 대기 중 결과를 폐기합니다.
- P 일시정지, R 초기화, Q/Esc 종료 등 기존 키는 유지합니다.

CNN 코드와 가중치는 저장소의 `fusion/`, `models/rgb_ksl30`을 사용하므로 별도 실험 폴더가 필요하지 않습니다.
새 PC에서는 Python 3.11 가상환경을 만든 뒤 `python -m pip install -r requirements.txt`, `python scripts/setup_assets.py`를 실행하세요.
CMD 파일은 기본 `.venv`를 사용하며, 기존 로컬 실험 환경이 설치된 PC에서는 그 환경을 우선 재사용합니다.
CNN 의존성이나 가중치가 준비되지 않으면 키포인트 단독으로 복귀하며 화면에 오류가 표시됩니다.

모델 가중치를 다시 학습하거나 합쳐 저장하지 않았습니다.

키포인트가 확정되면 즉시 기존 경로를 사용합니다. 비게임 수어가 확정되면 CNN으로 게임 명령을 만들지 않습니다.
애매한 결과에서만 같은 시간 구간의 원본 영상·추적 관절로 손/상반신 ROI를 만들고 RGB 모델을 백그라운드 실행합니다.
CNN이 같은 게임 후보에 충분한 점수를 줄 때만 키포인트 80%, CNN 20%로 재판정합니다.
기존 전체 점수·게임 상대 점수 거절 조건과 연속 확인·쿨다운도 적용됩니다.
CNN만으로 명령을 확정하거나, 후보가 다른 결과를 강제로 조합하지 않습니다.

작업 스레드는 게임 상태를 직접 바꾸지 않습니다. 메인 루프가 결과를 확인합니다.
오래된 결과(1.5초 초과), 후보가 바뀐 결과, 초기화/일시정지/모드 전환 전의 결과는 사용하지 않습니다.
CNN 오류 시 키포인트 단독으로 복귀합니다. 화면 아래에 사용 모드와 CNN 상태가 표시됩니다.
ROI 입력이 부족하면 해당 보조 결과만 보류합니다.
영상은 최대 약 2.4초의 메모리 버퍼로만 유지하고 파일 저장·전송하지 않습니다.

실시간 손 좌표로 ROI를 구성하므로 실험 프로그램의 재추적 경로와 완전히 같은 입력은 아닙니다.
CPU 사용량이 늘거나 CNN 결과가 오래 걸리면 보조가 보류될 수 있습니다. 실제 인식률 개선은 사용자 테스트가 필요합니다.
B 키로 언제든 기존 판정으로 돌아갈 수 있습니다. 새 기능이 불필요하면 기존 실행 파일만 사용하면 됩니다.
